# Derived AI profiles

This directory may contain optional AI-generated snapshots of Larry's food profile.

Derived profiles are caches, not truth.

They may summarize patterns such as:
- stable preferences;
- current tendencies;
- contradictions;
- uncertainty;
- evidence pointers.

A profile should include:
- generated_at;
- source cutoff/version;
- claims;
- confidence or uncertainty;
- evidence IDs;
- counterevidence/contradictions when relevant.

Important:
- meal writes do not update this directory;
- deterministic GitHub indexing does not require a model;
- profiles may be regenerated on demand or periodically by an authorized AI;
- deleting every derived profile must not destroy Larry's original memories.

Until an actual profile is generated, agents should infer from canonical evidence at query time.
